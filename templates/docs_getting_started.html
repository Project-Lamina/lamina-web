Lamina compiler · Guide

Getting started

Install the Lamina driver, compile a small module written in Lamina IR, and run it. The compiler is the lamina binary. The rest of the toolchain, ras and weld, is optional.

What you write

Lamina IR is a text format. You write it by hand, or a frontend writes it for you, or you build it in Rust with IRBuilder. The compiler lowers it, optimizes it, and generates machine code for one target.

Install the driver

$ cargo install lamina
$ lamina --version

cargo install lamina gets the crates.io release{{#if lamina_version}} {{lamina_version}}{{/if}}, which is older than the source this page follows. The IR below was checked against that source. From a source checkout, run cargo run -- in place of lamina. Everything after -- is passed to the driver.

A first module

Save this as answer.lamina. @main is the program's entry point, and its return value becomes the exit status.

fn @main() -> i64 {
  entry:
    %answer = add.i64 40, 2
    ret.i64 %answer
}
$ lamina answer.lamina -o answer
$ ./answer
$ echo $?
42

The default path compiles to assembly, assembles it, and links an executable. The exit status is 42.

Write output

A program writes text one byte at a time with writebyte. This one prints Hi and a newline:

fn @main() -> i64 {
  entry:
    %a = writebyte 72
    %b = writebyte 105
    %c = writebyte 10
    ret.i64 0
}

More ways to write output, including printf through @extern, are on Output and I/O.

Choose what the driver produces

ExecutableThe default. Compiles, assembles and links a native program.

Assembly--emit-asm writes an assembly file and stops before assembling or linking.

LUMIR--emit-mir writes a .lumir file next to the input and stops. See LUMIR.

JIT--jit compiles and runs the module in the current process, in a default build. The nightly feature is needed only for the JIT API of the Rust and C bindings.

$ lamina answer.lamina --emit-asm -o answer.s
$ lamina answer.lamina --emit-mir
$ lamina answer.lamina --target x86_64_linux -o answer

Choose the assembler and linker

The driver calls an assembler and a linker to make an executable. --assembler selects the assembler, and -c selects the linker. To build through this project's own tools, use ras and weld:

$ lamina answer.lamina --assembler ras -c weld -o answer

See ras and weld for installing them.
