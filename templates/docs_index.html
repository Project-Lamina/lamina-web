Products

Five parts, one toolchain.

Lamina is the compiler. ras and weld replace GNU as and ld in a build. camina is an early C front end that targets Lamina. lamina-c exposes the compiler to C programs.

Lamina / Compiler

Lamina

A typed, block-based IR compiled to native code. Covers the IR language, instructions, I/O, the runtime, LUMIR, the driver, targets, and the Rust API.

Start with the compiler → Toolchain

ras

An assembler that writes ELF64, Mach-O and COFF objects. Works in place of GNU as.

Read the ras docs → Toolchain

weld

A linker for x86_64 Linux, macOS and Windows executables. Static executables work; shared objects do not.

Read the weld docs → Front end

camina

A C compiler that lowers a subset of C to Lamina IR. It compiles small programs, but produces no output from stdio calls yet.

Read the camina docs → Bindings

lamina-c

A C API over the IRBuilder, module serialization and AOT assembly output. Development archives for Linux x86_64.

Read the C bindings → External
