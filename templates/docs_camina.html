camina, a C compiler for Lamina

camina reads a C file and lowers it to Lamina IR, then calls Lamina to produce an executable. It compiles a useful subset of C. It is early work. Programs it accepts run correctly in the cases tested here. Much of C is not supported yet, and the parts that are supported are not complete.

Name

The project is called camina. The crate and binary are still named cina in its manifest. Build the crate, and run the binary as cina.

Current state

CompilesFunctions with int, long, unsigned int, char, double and void types. Global variables with initializers. if, else, while, for, break, continue, the ternary operator, compound assignment, ++ and --, casts, sizeof(type), and recursion.

Not parsedswitch, do ... while loops, arrays, and struct declarations with member access.

Refused in loweringA pointer local, with or without an initializer: int *p = &v; and int *p; p = &v; both fail with Only simple variable declarations are supported.

Standard I/OCalls to printf, puts, putchar and the other stdio names compile when <stdio.h> is included. The lowering discards them, so a program that prints produces no output. Do not rely on any output from camina programs yet.

Division by zeroNot diagnosed. A program that divides by zero at run time is terminated by the signal.

Build and run

camina is built from its own repository. It depends on the Lamina crates in the sibling directory and on the default toolchain, so build it from a checkout that has both.

$ cargo build --release
$ target/release/cina program.c

The compiler writes an executable next to the source, named after it. Its exit status is the value main returns.

An example that works

This program sums a value over a loop, calling a helper function. It exits with status 20.

int add(int a, int b) {
    return a + b;
}

int main(void) {
    int total = 0;
    int i;
    for (i = 0; i < 5; i++) {
        total += add(i, 2);
    }
    return total;
}

Recursion, unsigned division, and the other constructs in the table above returned the expected values in the cases tested.

What does not compile

Each of these fails at the stage shown. Rewrite the code to avoid them until the feature exists.

/* fails: switch is not parsed */
int main(void) {
    int x = 2;
    switch (x) {
        case 2: return 5;
        default: return 0;
    }
}

/* fails: pointer locals are refused in lowering */
int main(void) {
    int v = 3;
    int *p = &v;
    return *p;
}
