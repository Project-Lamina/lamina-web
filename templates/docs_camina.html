camina, a C compiler for Lamina

camina reads a C file and lowers it to Lamina IR, then calls Lamina to produce an executable. It compiles a useful subset of C. It is early work. Programs it accepts run correctly in the cases tested here. Much of C is not supported yet, and the parts that are supported are not complete.

Name

The project is called camina. The crate and binary are still named cina in its manifest. Build the crate, and run the binary as cina.

Current state

CompilesFunctions with int, long, unsigned int, char, double and void types. Global variables with initializers. if, else, while, for, break, continue, the ternary operator, compound assignment, ++ and --, casts, sizeof(type), recursion, switch with case and default, and pointer locals such as int *p = &v; or int *p; p = &v;. These were run in the cases tested and returned the expected values.

Not parseddo ... while loops, array declarations and indexing, and struct declarations. Each fails in the parser with an error that names the token.

Standard I/OCalls to printf, puts and putchar with <stdio.h> included reach standard output. Checked for printf("hi\n"), puts and putchar. Other stdio functions were not checked.

Division by zeroNot diagnosed. A program that divides by zero at run time is terminated by the signal (exit 136, SIGFPE).

Build and run

camina is built from its own repository. It depends on the Lamina crates in the sibling directory and on the default toolchain, so build it from a checkout that has both.

$ cargo build --release
$ target/release/cina program.c

The compiler writes an executable next to the source, named after it. Its exit status is the value main returns. While it runs, it prints each stage to standard output, starting with the token stream.

An example that works

This program sums a value over a loop, calling a helper function. It exits with status 20.

int add(int a, int b) {
    return a + b;
}

int main(void) {
    int total = 0;
    int i;
    for (i = 0; i < 5; i++) {
        total += add(i, 2);
    }
    return total;
}

Recursion, unsigned division, and the other constructs in the table above returned the expected values in the cases tested.

What does not compile

Each of these fails at the stage shown. Rewrite the code to avoid them until the feature exists.

/* fails: arrays are not parsed */
int main(void) {
    int a[3];
    a[0] = 4;
    return a[0];
}

/* fails: struct declarations are not parsed */
struct P { int x; };
int main(void) { return 1; }

/* fails: do ... while is not parsed */
int main(void) {
    int i = 0;
    do { i++; } while (i < 3);
    return i;
}
